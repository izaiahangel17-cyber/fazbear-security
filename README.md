# fazbear-security

Roblox Studio plugin that builds **Freddy Fazbear's Security Map** into your
place — rooms, doors, vents, and a multiplayer-friendly camera tablet.

The plugin source lives in [`plugin/FazbearSecurityPlugin.server.lua`](./plugin).
See the PR for the full README, install instructions, and feature list.

## Lint / format

```bash
stylua --check plugin/
selene plugin/
```
